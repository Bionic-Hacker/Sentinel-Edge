# v0.2.0 — Phase 2: secure application foundation

Everything here runs locally; no AWS resources exist yet ([ADR-0016](../adr/0016-local-first-phase-order.md)).

## What's new
- **Authentication:** Argon2id; 15-minute JWTs validated against a live session on every request;
  rotating refresh tokens in a `__Host-` HttpOnly, Secure, SameSite=Strict cookie with reuse
  (theft) detection; TOTP MFA with encrypted secrets, replay protection and single-use recovery
  codes, mandatory for ADMIN and SECURITY_ENGINEER; lockout; enumeration-resistant errors; CSRF
  defenses; password reset through a local outbox.
- **No default credentials:** `make create-admin` issues a one-time password; first sign-in forces
  a new password and MFA. Admins invite users by one-time link and never handle passwords.
- **Authorization:** five roles, declared on every route and verified by an automated sweep;
  object-level checks on user records; user administration with self-lockout and last-admin
  protection.
- **Tamper-evident audit log:** hash chain, append-only by grant and trigger, concurrency-safe,
  verifiable from the CLI, API and UI.
- **Database least privilege:** separate migrator and runtime roles with a privilege-matrix test;
  secrets scoped per container; verified TLS required when deployed.
- **Frontend:** sign-in with MFA, setup flow with a locally rendered QR code, password reset,
  user administration, audit log viewer; token kept in memory with cross-tab refresh locking.
- **Tooling:** `make verify-hardening`, `make smoke`, schema-drift gate, exceptions register.

## Evidence
- 291 backend tests (99% coverage) against real PostgreSQL; 40 frontend tests.
- `make smoke`: 26 end-to-end checks against the running stack.
- Verified in headless Chromium: full first-run journey, empty web storage, refresh cookie
  invisible to JavaScript, no console errors.
- Bandit, Ruff, mypy (strict), pip-audit, npm audit, Gitleaks, actionlint: clean.

## Bugs found by the new tests (fixed, with regression tests)
- Unicode digits passed the MFA "6 digits" check and crashed the constant-time comparison (500).
- Role values loaded as plain strings, so an identity comparison against the enum never matched.

## Upgrading from v0.1.0
The database and `.env` must be recreated once (new roles and keys):
`make clean && mv .env .env.phase1.bak && make env && make dev && make create-admin EMAIL=you@example.com`
