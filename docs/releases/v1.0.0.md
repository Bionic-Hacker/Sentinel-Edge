# v1.0.0 — Phase 12: hardening, final assessment, interview demo

The last phase. SentinelEdge is complete: all twelve phases are built, every control the threat
model names is implemented, and the platform has been assessed against its own threat model
([SECURITY_ASSESSMENT.md](../../SECURITY_ASSESSMENT.md)) with no open item left.

## What's new
- **Signing-key rotation:** access tokens carry a key ID; `SENTINEL_JWT_PREVIOUS_SIGNING_KEY`
  verifies tokens signed before a rotation, so the key changes without signing everyone out. An
  unknown key ID is refused.
- **The live edge scanned:** `make dast-edge` runs a passive ZAP baseline through CloudFront and
  AWS WAF and puts the report through the same scan gate as CI (C-CICD-12). It now says plainly
  when AWS is not signed in or no window is open.
- **NIST SP 800-53 Rev. 5 crosswalk** ([docs/governance](../governance/nist-800-53-crosswalk.md)):
  every family with its coverage and gaps; a test fails if it cites a control that does not exist
  or leaves an implemented one out.
- **Runbooks:** application outage, origin connectivity, TLS failure, certificate expiration and
  WAF false positive. **Disaster recovery** with RTO and RPO ([docs](../disaster-recovery.md)).
- **Final documents:** `SECURITY_ASSESSMENT.md`, `INTERVIEW_DEMO.md` (five scenarios, each from
  attack to validation), `LESSONS_LEARNED.md`, `ARCHITECTURE.md`, `THREAT_MODEL.md`.
- **SOC backdrops:** each sidebar tab has its own console code and pattern, drawn in CSS from the
  theme accent, in light and dark themes. No image files; cards keep solid surfaces.
- **Deploy gate:** a CI check still running is labelled `wait`, not `FAIL`.

## Security
- C-CICD-12 implemented: none planned. Threat model v0.15; catalogue 100 threats, 115 controls.
- The notes that pointed at Phase 12 are closed with reasons: per-request database load and
  in-request correlation reviewed and accepted; no retention policy (the environment and its
  data are destroyed after every window); a minimal base image is the next hardening step.

## Evidence
- Third deploy window (14–15 October 2026): `make edge-check` passed; ZAP baseline of the live
  edge 63 rules passed, 0 failures, 1 low and 3 informational warnings, nothing blocking; the
  audit chain checked against its anchor; the window destroyed afterwards.
- 1,076 backend tests (97.3%), 128 frontend tests; Ruff, mypy, ESLint and the scan gate clean.

## Upgrading from v0.11.0
Nothing to migrate. To rotate the signing key, see `.env.example`
(`SENTINEL_JWT_PREVIOUS_SIGNING_KEY`).
